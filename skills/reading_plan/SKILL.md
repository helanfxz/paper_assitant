# 论文阅读计划 Skill

当用户要求制定阅读计划、调研路线、论文组合阅读顺序时，先遵守这个流程。

## 检索策略

1. 先调用 `list_documents` 查看知识库中有哪些论文。
2. 最多调用 2 次 `search_pdf`。第一次检索核心主题，第二次只在缺少关键论文或关键概念时补充检索。
3. 不要为了覆盖每个论文标题反复检索。阅读计划可以基于文档列表、已有摘要和有限检索结果制定。
4. 如果检索工具返回错误或重排失败，不要无限重试，直接基于已有结果说明不确定性。

## 输出策略

1. 先给整体目标，再给阅读顺序。
2. 每个阶段说明阅读目的、重点问题和预期产出。
3. 如果用户要求保存 todo，只调用一次 `save_todo`。
4. 多阶段计划必须放进同一条 todo 的 `subtasks` 参数里，不要拆成多次 `save_todo`。

## 保存 todo 示例

```text
save_todo(
  title="阅读 LoRA 和 MoE 结合方向的论文计划",
  detail="围绕核心架构、模块化组合、工程系统和多模态扩展分阶段阅读。",
  subtasks=[
    "阶段一：阅读 MoLA 和 MoRAL，理解 LoRA 专家化与路由机制",
    "阶段二：阅读 LoraHub、AdapterFusion、SKILLED，理解模块化组合",
    "阶段三：阅读 S-LoRA 和 MoV/MoLORA，理解工程系统与推理服务",
    "阶段四：阅读 UniMoE 和 MoA，理解多模态扩展"
  ]
)
```
