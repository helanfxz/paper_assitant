## 设计理念

本项目的核心设计理念：

1. **职责分层**：App 编排、Context 组装、Runner 执行、Hook 拦截
2. **控制与业务分离**：harness 层负责控制流，业务逻辑在工具层
3. **统一出口**：所有系统上下文通过同一个 builder 生成
4. **错误恢复分层**：模型调用、工具执行分别处理
